# Fórum Hub - API REST 👩🏻‍💻👨🏼‍🏫
Conheça o Fórum Hub aqui você pode enviar as suas principais dúvidas sobre cursos. É uma API REST construída visando boas práticas de código, aplicando conhecimentos de SOLID.

## 🌟 Funcinalidades
- Autenticação e Autorização de usuários
- Documentação com Swagger e OpenAPI
- Testes unitários e de integração utilizando Mockito e JUnit
- Implementação de regras de negócios concisas
- Deploy na AWS ECS
- Conteinerização com Docker
- Migrações com Flyway
